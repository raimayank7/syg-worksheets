About this worksheet

Place value means that a digit is worth more or less depending on where it stands. In 4,318 the 3 is worth 300; in 4,381 it is worth 300 too, but the 8 has changed from 8 to 80. Expanded form asks the child to break a number into such parts: 4,318 = 4,000 + 300 + 10 + 8.

Numbers follow the Indian system here: ones, tens, hundreds, thousands, ten thousands, lakhs, with commas as 1,00,000.

Tips for parents and teachers

  • Draw a place value chart (Th, H, T, O) on top of the sheet and let the child write the digits in it first.
  • Zeros need care: 4,008 is 4,000 + 8. There are no hundreds and no tens to write.
  • Mix both types over a week. Expanded form builds the idea; the underlined digit checks it.

Common questions

What is the difference between face value and place value?

The face value of a digit is the digit itself. The place value is the digit multiplied by the value of its place. In 4,318 the face value of 3 is 3 and its place value is 300.
